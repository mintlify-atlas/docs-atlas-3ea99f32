Better Lyrics is a free, open-source browser extension that replaces YouTube Music's built-in lyrics panel with a far richer experience. Instead of static, unsynced text, it delivers time-synchronized lyrics that highlight word by word — or even syllable by syllable — as your song plays. You can click any line to jump directly to that moment in the track, switch between a library of community and commercial providers, translate lyrics into your language in real time, and style the entire interface with custom CSS themes. It runs quietly in the background with no accounts required and no external setup.

## How It Works

Better Lyrics injects directly into `music.youtube.com` using the browser's content script system. The extension uses a **dual-world architecture** defined in its manifest:

- **MAIN world scripts** (`src/videoQualityPage.ts`, `public/earlyInject.js`, `public/script.js`, `src/pageWorld.ts`) run in the same JavaScript context as the YouTube Music page itself. This allows them to read page state — such as the currently playing song's metadata and the player's current time — without crossing the extension boundary.

- **ISOLATED world scripts** (`src/index.ts`) run in a separate, sandboxed context. This is where the core extension logic lives: fetching lyrics from providers, injecting the lyrics UI into the DOM, managing settings, and coordinating translations. The isolation protects the extension from any JavaScript running on the page.

The two worlds communicate through custom DOM events (such as `blyrics-seek-to` and `blyrics-send-player-time`), which pass playback information cleanly across the boundary. The result is a lyrics panel that stays perfectly in sync with playback without requiring any modifications to YouTube Music's own code.

## Supported Browsers

Better Lyrics is published to all three major browser extension stores and works on any Chromium-based browser (Brave, Opera, Arc, and others) using the Chrome build.

| Browser | Store |
|---|---|
| Google Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/better-lyrics/effdbpeggelllpfkjppbokhmmiinhlmg) |
| Mozilla Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/better-lyrics/) |
| Microsoft Edge | [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/better-lyrics-lyrics-for/mjfeaklppoegooljmjicjdbiccgjdlhd) |

<Note>
  Better Lyrics only activates on **music.youtube.com**. It will not run on youtube.com or any other site. If you open a regular YouTube tab, the extension stays completely dormant.
</Note>
